# WorkTrack 💼⏱️

WorkTrack is a career, attendance, and salary tracking web application built with React, Vite, and Tailwind CSS.

## 🚀 Features

- 🏢 **Multi-Company Management**: Track current and past company profiles, job roles, joining dates, base salaries, daily rates, and overtime rates.
- 📅 **Daily Attendance Tracking**: Interactive calendar and log table with attendance status (Present, Half Day, Paid Leave, Weekly Off, Absent, Holiday) and daily earnings calculation.
- ⏰ **Shift Management**: Shift configurations, day/night shift rules, break times, and grace periods.
- 💰 **Salary Calculator**: Flexible salary computation methods (calendar days vs scheduled working days), deductions, overtime pay, and itemized salary slips.
- ⏳ **Overtime Tracker**: Multiplier calculations, custom overtime hours logging, and payout tracking.
- 💳 **Salary Payments**: Track paid, pending, and partial salary disbursements with transaction IDs and receipt logs.
- 📊 **Monthly Reports & Analytics**: Interactive charts powered by Recharts for monthly attendance and gross earnings trends.
- 🔄 **Cloud & Local Sync**: Google Apps Script / Google Sheets 7-tab live sync and local JSON file backups.
- 🌙 **Dark Mode & Responsive UI**: Sleek modern UI built with Tailwind CSS, Lucide icons, and responsive layouts.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React**
- **Recharts**
- **Day.js**
- **SheetJS (XLSX)**

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
